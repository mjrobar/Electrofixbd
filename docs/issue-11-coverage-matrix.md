## Backward-compatible data rules for AI Studio

- Existing public services/work/testimonial JSON field names, filters, pagination,
  stable IDs, slugs, booking/contact response shapes and tracking allowlist remain.
  Drafts/history/archive markers are never added to those public responses.
- Existing database publications remain live through migration 004. Admin creation
  starts unpublished. Editing saves `admin_draft`; publish atomically promotes it.
  Unpublish/archive remove database records from public reads. Restoring an archive
  leaves it unpublished; restoring a historical version creates a private draft.
- Site JSON publication uses its existing `draft`/`published` separation. Empty/all-inactive drafts cannot silently replace a publication; use the explicit Unpublish module action. Active hero slides require a headline, image and primary button label. Optional
  hero/business metadata is additive. Old saved publications need not contain the
  new fields. Keep explicit legacy fallbacks for absent metadata and known IDs.
- Hero `actions_configured` defaults false for legacy data. For a known legacy slide ID, retain shipped callback/secondary-button metadata while this flag is false; only true explicitly opts into CMS action overrides. New admin slides start with the opt-in true. This distinguishes an intentional secondary action of `none` from an untouched partial import. Hero `navigate` requires a nonempty safe destination. Never convert a booking
  callback to an empty link. Phone/WhatsApp actions derive from business settings;
  new metadata stores action names and service hints, never executable code.
- Honor active flags and ordered stable IDs after integrating site JSON. Do not
  silently clear a whole component when a module is unavailable or still empty.
  An empty publication versus intentional hiding requires an agreed frontend
  policy because Issue #9 intentionally retains the static baseline.
- URL media only: HTTPS public host or single-slash app-relative path. No browser
  upload endpoint, filesystem path, data URL, SVG upload processor, server-side URL
  fetcher or remote HTML importer exists. Use licensed/consented direct image/video
  URLs. Keep script CSP restricted to self and render all editorial strings as text.

## Integration gate

AI Studio should manually import this backend/admin branch without overwriting its
public source. Connect the site JSON modules in a **separate frontend-owned change**,
using the mapping above and `phase-4b-ai-studio-handoff.md`. Resolve local-only
feedback and empty-publication semantics before declaring whole-site production
acceptance. Compare home, services/direct slugs, works, contact, hero callbacks,
FAQ accordion, lookup, phone/WhatsApp/social links and responsive layouts under
published, draft-only, empty and API-failure states. No compatibility claim extends
to that still-unimplemented frontend wiring.
